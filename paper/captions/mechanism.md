**Figure 5. Why only IM generalizes across environments.** (a-c) For each
model, one task-responsive place cell present in both env A and env B,
trial-averaged firing rate around CS onset (mean +/- SEM across trials), env
A (solid line) vs. env B (dashed line). Shaded regions mark tone/trace/shock
as in Figure 1a.

IM's task response is independent of place-field location, so the same
cell's response shape is preserved through remapping -- the A and B traces
overlay closely. PDM's task response only appears while the animal occupies
the cell's place field; since that field is redrawn independently per
environment, the same cell's population-level response pattern changes from
A to B. ADM changes further still, since its response additionally depends
on running state at each moment.

**(d) Population stability.** The three example cells in (a-c) are
illustrative, not evidence on their own -- this panel is the quantitative
counterpart: for every cell that is place+task-responsive in both envs, the
Pearson correlation between its own trial-averaged CS-onset response in env
A and in env B (individual cells as points; mean +/- 95% CI across cells
overlaid per model). A cell whose trace is flat (no CS-onset modulation) in
either env has an undefined correlation and is excluded. High correlation =
the cell's response shape survives remapping; low/negative = it doesn't.
